# library/ — AI 프롬프트 수집 보관함

좋은 AI 프롬프트를 발견할 때마다 한 곳에 모아두는 개인 라이브러리.
한 프롬프트 = 한 `.md` 파일. 텍스트 길이 제한 없음. 태그로 분류.
웹(`web/`)의 **라이브러리** 섹션에서 태그 필터·복사·`.md` 내보내기가 된다.

```
library/
├── README.md          # 이 문서
├── _TEMPLATE.md       # 새 항목 만들 때 복사해서 쓰는 틀
└── <slug>.md          # 프롬프트 한 개당 한 파일
```

`README.md` 와 `_`(언더스코어)로 시작하는 파일은 웹 컬렉션에서 제외된다.

---

## 새 프롬프트 추가하기

### 방법 A — slash command (권장)
```
/add-prompt
```
프롬프트 본문 · 제목 · 태그 · 출처를 차례로 물어본 뒤 `library/<slug>.md` 를 만들어 준다.

### 방법 B — 직접 파일 생성
1. `_TEMPLATE.md` 를 `library/<slug>.md` 로 복사한다.
   - `<slug>` 는 영문 소문자 + 하이픈 권장 (예: `structured-code-review`, `blog-outline-ko`).
   - 날짜 prefix 를 붙여도 됨 (예: `2026-05-12-structured-code-review`). 정렬은 `added` 프론트매터 기준이라 필수는 아님.
2. 프론트매터를 채우고, **본문(`---` 아래)에 프롬프트 텍스트만** 그대로 붙여넣는다.
3. 끝.

---

## 파일 형식

```markdown
---
title: 구조화된 코드 리뷰 요청
tags: [개발, 보안]
source: https://example.com/where-i-found-it
added: 2026-05-12
model: any
note: PR diff 를 4개 관점(보안/성능/가독성/테스트)으로 나눠 보게 함. 길면 파일 단위로 잘라서.
summary: PR diff 를 4개 관점으로 나눠 리뷰하게 하는 프롬프트
---

여기서부터 프론트매터 아래 전체가 "프롬프트 본문"이다.
웹의 복사 버튼은 이 본문을 그대로 클립보드에 넣는다.
줄바꿈·코드블록·길이 모두 자유. 설명/메모는 본문에 섞지 말고 위의 note 에 둔다.
```

### 프론트매터 필드

| 필드 | 필수 | 설명 |
|------|------|------|
| `title` | ✅ | 사람이 읽는 제목. 한국어 OK. |
| `tags` | 권장 | 문자열 배열. 자유롭게. 아래 "추천 태그" 참고. |
| `source` | 선택 | 어디서 발견했는지. URL, 책 제목, 사람 이름, "직접 작성" 등. |
| `added` | 권장 | 추가한 날짜 `YYYY-MM-DD`. 목록 정렬 기준. |
| `model` | 선택 | 어떤 모델용인지 / 검증한 모델. `any`, `claude`, `gpt`, `gemini` 등. 기본 `any`. |
| `note` | 선택 | 사용 팁·주의·변형 메모. 본문에 안 섞기 위함. |
| `summary` | 선택 | 카드/목록에 보일 한 줄 요약. 없으면 `note` 또는 본문 첫 줄로 대체. |

### 본문 규칙
- 본문 = **프롬프트 그 자체**. 그대로 복사해 쓸 수 있어야 한다.
- 설명·맥락·출처 코멘트는 본문에 넣지 말고 `note` / `source` 프론트매터로.
- 변형이 여러 개면 별도 파일로 나누는 걸 권장 (한 파일 = 한 프롬프트).

## 추천 태그 (자유롭게 추가·변형 가능)

`보안` · `창작` · `교육` · `업무` · `자동화` · `개발` · `글쓰기` · `리서치` · `요약` · `번역` · `데이터` · `이미지` · `프롬프트설계` · `에이전트` · `면접` · `기획`

> 태그는 강제 목록이 아니다. 새 태그를 그냥 쓰면 웹의 필터 칩에 자동으로 나타난다.
> 다만 표기는 통일하자 (예: `글쓰기` vs `작문` 섞지 않기).

## 내보내기

- **웹**: `/library` 페이지 상단 "전체 `.md` 다운로드" → 모든 항목을 한 파일로. 개별 항목 페이지에서는 "이 프롬프트 `.md` 저장".
- **로컬**: `/export-library` slash command — 전체 또는 특정 태그만 골라 한 개의 `.md` 로 합쳐 저장.
