# Claude Code 보안 온보딩 (15분)

> 이 문서는 **본인**과 **가르칠 대상**이 Claude Code 를 처음 켤 때 함께 읽는 문서다.
> 순서대로 따라오면 15분 안에 "적어도 큰 사고는 안 나는" 수준까지 올라간다.

---

## 0. 왜 이게 필요한가 (2분)

Claude Code 는 **로컬 파일을 읽고 쓰고 실행할 수 있다**. 게다가 우리는:

- 집, 회사, 모바일, 공유 기기 등 **여러 환경**에서 쓰고,
- 개인 / 회사 / 공용 **여러 계정**에 동시에 로그인하고,
- 점점 **레포 기반**으로 일한다 (= 실수 한 번이면 git에 민감정보가 공개된다).

따라서 "내 워크스테이션 안에서만 잘 쓰면 된다"는 옛 감각으로는 위험하다.
본 레포는 그 위험을 **체크리스트화** 해서 매 세션 자동으로 돌린다.

## 1. 처음 5분: 환경 점검 (5분)

### Step 1-1. 내가 어디서 뭘 쓰고 있는지 말해보기
소리 내서 (또는 한 줄 메모로) 다음을 **세 문장**으로 정리한다.

1. "지금 나는 __(집 데스크탑 / 회사 노트북 / 모바일 / 공용 PC)__ 에 있다."
2. "로그인된 Claude 계정은 __(개인 / 회사 / 공용)__, GitHub 계정은 __(개인 / 회사)__ 이다."
3. "지금 할 일은 __(신규 프로젝트 시작 / 기존 레포 작업 / 학습·실험)__ 이다."

### Step 1-2. 명령으로 확인하기
```bash
gh auth status
git config --global user.email
git config --global user.name
```
세 출력이 내가 말한 문장과 **일치**하는가? 불일치면 수정하거나 중단.

### Step 1-3. 레포 가시성 확인
- 이미 레포가 있다: `gh repo view --json visibility,isPrivate`
- 신규 생성 예정: 기본 **private** 로 시작한다고 결정.

## 2. 다음 5분: 도구 설정 (5분)

### Step 2-1. 이 레포를 도구로 쓸 수 있게 `cd`
```bash
git clone https://github.com/<you>/meticulous-monet.git
cd meticulous-monet
```

### Step 2-2. Claude Code 에 이 레포의 규칙을 자동 로드시키기
이 레포의 `CLAUDE.md` 는 Claude Code 가 세션 시작 시 자동으로 읽는다.
**주의**: 타 프로젝트에서도 같은 규칙을 쓰고 싶으면 내용을 해당 프로젝트 `CLAUDE.md` 에 복사하거나 링크한다.

### Step 2-3. 세션 시작 시 자동 체크
`.claude/settings.json` 에 `SessionStart` hook 이 있다. Claude Code 실행 직후 체크리스트 리마인드가 뜬다.
**끄고 싶다**면 `settings.local.json` 에서 오버라이드 (본인 책임).

### Step 2-4. 주요 slash command 익히기
| 명령 | 언제 쓰나 |
| --- | --- |
| `/security-check` | 아무때나, 스스로 점검하고 싶을 때 |
| `/new-project` | 신규 프로젝트 시작하려 할 때 |
| `/pre-commit-check` | 커밋 직전 |
| `/update-checklist` | 새 보안 이슈를 경험/목격했을 때 |
| `/new-prompt` | "오늘의 새로운 프롬프트" 기록 |
| `/startup` | 초보자/환경/신규·기존 상황별 시작 프롬프트 선택 |

## 3. 마지막 3분: 사고를 부르는 습관 제거 (3분)

다음 **세 가지만** 당장 버려도 큰 사고의 70%는 막는다.

### ❌ 버릴 것 1. `git add -A` / `git add .`
- 이유: 실험하다 생긴 `.env`, 덤프 파일, IDE 임시파일이 섞인다.
- 대신: 파일을 명시적으로 나열. `git status` 를 한 번 보고 추가.

### ❌ 버릴 것 2. "일단 커밋하고 나중에 정리"
- 이유: git 히스토리는 사실상 영속적이다. 특히 public에 한 번 나간 비밀은 돌이킬 수 없다.
- 대신: 의심되면 **커밋하지 않는다**. 일단 로컬에 남겨두고 확인.

### ❌ 버릴 것 3. `--no-verify`
- 이유: pre-commit hook 은 바로 이런 사고를 막으려고 있다.
- 대신: hook 이 실패하면 **원인 수정**. 피해가지 않는다.
