# prompts/optional/routine-scope-review.md — 자동화 에이전트 작업 범위·권한 재확인

- **언제 쓰나**: Routines / 스케줄 자동화 / GitHub Actions 등 "자동으로 도는 것" 이 있을 때. 월 1회 권장.
- **예상 소요시간**: 10분.

---

## Claude 에게 붙여넣을 프롬프트

```
이 프로젝트(혹은 이 계정)에서 자동으로 돌고 있는 작업을 모두 찾아서 점검해줘.

1) 자동화 소스 찾기:
   - `.github/workflows/*.yml`
   - `cron` / systemd timer / PM2 / scheduler 설정
   - Claude Routines / 외부 스케줄러 (Zapier, n8n 등)
   - 서버에서 도는 데몬 스크립트
2) 각 자동화에 대해 다음을 표로 정리:
   - 이름 / 트리거 (cron 주기, 이벤트 등)
   - 접근하는 레포 / 디렉토리
   - 연결되는 외부 서비스
   - 사용하는 토큰·시크릿 이름과 **필요 스코프**
   - 실패 시 중단 조건 / 알림 경로
3) 다음 항목을 ⚠️ 로 표시:
   - 필요 이상의 write 권한
   - 만료일이 없거나 90일 넘은 토큰
   - 실패 시 조용히 재시도만 하는 것
   - "어떤 레포까지" 닿는지 명확하지 않은 것
4) 마지막에, 줄일 수 있는 권한 / 없애도 되는 자동화를 추천.
```
