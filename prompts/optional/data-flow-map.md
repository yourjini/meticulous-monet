# 외부로 나가는 데이터 흐름 맵핑

- **언제 쓰나**: 새 외부 API 연동 추가 시 / 분기에 한 번.
- **예상 소요시간**: 10~20분.
- **출력**: `docs/DATA_FLOW.md` (없으면 생성).

---

## Claude 에게 붙여넣을 프롬프트

```
이 프로젝트에서 외부로 나가는 모든 네트워크 호출을 찾아서 표로 정리해줘.

절차:
1) `fetch(`, `axios`, `http.request`, `requests.`, `urllib`, `httpx`, SDK import 등
   외부 호출에 쓰일 법한 패턴을 grep.
2) 각 호출마다 다음을 뽑아줘:
   - 파일 경로 : 라인 번호
   - 대상 도메인 / 서비스명
   - 요청 메서드 / 엔드포인트
   - **보내는 필드 목록** (payload 구조)
   - 응답에서 저장하는 필드
3) 민감 후보 필드(이메일, 이름, 전화, 주소, 위치, 결제, 건강, 아동 관련)는 별도로 **⚠️** 표시.
4) 결과를 `docs/DATA_FLOW.md` 에 저장 제안. 기존 파일이 있으면 diff 로 갱신.
5) ⚠️ 가 하나라도 있으면 마지막에 이렇게 물어줘:
   "이 항목에 대한 데이터 처리 계약(DPA) 또는 법적 근거가 준비되어 있나요?"
```
