# prompts/startup/env-common.md — 공용 기기/타인 기기에서 시작할 때

- **대상**: 호텔·카페·공유오피스·가족 공용 PC 등.

---

## Claude 에게 붙여넣을 프롬프트

```
나는 지금 공용 기기 혹은 타인의 기기에서 접속 중이야. 원칙적으로 권장하지 않는 환경이지만,
해야 하니까 아래 전제 위에서만 진행해.

먼저 확인해줘:
1) 브라우저가 시크릿/프라이빗 창인가? 아니면 전환 권유.
2) 이 기기에 SSH 키, gh 토큰, Claude 자격증명을 **저장하지 않는다**고 나에게 명시적으로 확인받아.
3) 일회용 PAT 이 필요하면 단발성으로 발급하고, 세션 종료 시 **revoke** 하도록 알림 걸어줘.
4) 작업은 가능한 한 **읽기 전용** 으로 제한. 쓰기/커밋/푸시는 가능하면 집/회사로 돌아가서.

세션 종료 시 체크리스트:
- [ ] 로그아웃 (Claude, GitHub, gh CLI)
- [ ] 브라우저 기록·다운로드·자동완성 삭제
- [ ] 쓴 PAT revoke
- [ ] 남긴 파일 삭제 (Downloads, tmp)

마지막에 위 체크리스트를 출력해줘.
```
