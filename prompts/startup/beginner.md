# 초보자용 시작 프롬프트

- **대상**: Claude Code 를 처음 쓰거나, 본 레포의 원칙을 오늘 처음 배우는 사람.
- **예상 소요시간**: 10~15분. 빨리 끝내는 게 목적이 아니다.

---

## Claude 에게 붙여넣을 프롬프트

```
나는 Claude Code 를 처음 제대로 쓰기 시작하는 사용자야. 아래 순서로 나를 안내해줘.

1) 먼저 `docs/ONBOARDING.md` 가 있으면 그 문서의 흐름을 따라 나를 인터뷰해.
2) 질문은 한 번에 하나씩. 내 답을 기다려.
3) 내가 지금:
   - 어디서 (환경) 쓰는지,
   - 어느 계정으로 (Claude/GitHub) 쓰는지,
   - 오늘 하고 싶은 일이 뭔지
   이 세 가지를 명확히 한 뒤에만 다음 단계로 넘어가.
4) 다음으로 `prompts/required/pre-work.md` 에 정의된 3가지 체크를 함께 실행.
5) 그 후 내가 하려는 일이 "신규 프로젝트 시작" 이면 `/new-project`,
   "기존 레포 작업" 이면 `/security-check`, "단순 학습/실험" 이면 그대로 진행해.
6) 중간에 내가 모르는 용어(예: SSH key, PAT, 레포 가시성)가 나오면 먼저 한 줄 설명하고
   넘어가. 설명 없이 명령만 내리지 마.
7) 마지막에, 오늘 내가 배운 세 가지를 요약해서 알려줘.
```
