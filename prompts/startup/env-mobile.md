## Claude 에게 붙여넣을 프롬프트

```
나는 지금 모바일/태블릿에서 작업할 거야. 로컬 폴더 접근이 제한적이고,
복붙 실수 위험이 상대적으로 크다는 걸 염두에 둬.

먼저 확인:
1) 이 세션을 "공용 디스플레이/캐스팅" 에 띄우고 있지 않은가?
2) 이 기기에 SSH 키/PAT 이 저장돼 있지는 않은가?
3) 작업 대상 레포를 로컬 경로 대신 **레포 기반** 으로만 참조할 것 — git 웹 UI, Codespaces, 또는
   레포 원격 URL 을 통해서만 진행한다고 나에게 상기시켜줘.

나한테 붙여넣기 전에 한 번 더 "지금 이 텍스트에 민감정보가 있는지"
확인하라고 주기적으로 알려줘(특히 5분 이상 쉬고 돌아왔을 때).

`docs/MULTI_ENV_GUIDE.md` 의 "📱 모바일" 섹션을 요약해서 먼저 읽어줘.
```
