# prompts/startup/intermediate.md — 중급 사용자용 시작 프롬프트

- **대상**: 본 레포의 원칙을 이미 한 번 훑은 사람. 매일 세션 시작 시 붙여넣는다.

---

## Claude 에게 붙여넣을 프롬프트

```
세션 시작. `prompts/required/pre-work.md` 체크만 빠르게 돌려줘.
내가 답하면, 오늘의 한 줄 목표를 내가 말한 뒤에만 작업을 시작해.
중간에 커밋이나 푸시가 필요해지면, 그 전에 반드시 `prompts/required/pre-commit.md` 의 절차를 먼저 실행해.
배포가 필요하면 `prompts/required/pre-deploy.md` 를 먼저 실행해.
```
