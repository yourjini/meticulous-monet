# prompts/startup/env-office.md — 회사에서 시작할 때

- **대상**: 회사 데스크탑/노트북에서 회사 계정으로 작업.

---

## Claude 에게 붙여넣을 프롬프트

```
나는 지금 회사 기기에서 회사 계정으로 작업할 거야.

먼저 확인해줘:
1) `git config --global user.email` 이 회사 이메일인가? 아니면 중단.
2) `gh auth status` 로 회사 조직 GitHub 가 활성인가?
3) 작업할 레포가 회사 조직 하에 있는가? 개인 계정 하에 실수로 클론되어 있지 않은가?

주의:
- 회사 코드/고객 데이터/이슈 본문을 **개인 Claude 세션에 붙여넣지 않는다**.
- 회사 AI 사용 정책 / 금지 모델 여부를 내가 이미 알고 있는지 확인.
- VPN 필요 여부.

`docs/MULTI_ENV_GUIDE.md` 의 "🏢 회사" 섹션을 한 줄씩 물어줘.
```
