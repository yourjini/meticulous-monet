---

세션 시작. 아래 질문을 **순서대로** 해서 어떤 startup 프롬프트를 쓸지 고르고 그 내용을 실행해.

질문 1. 숙련도: 초보자 / 중급
질문 2. 환경: 집 / 회사 / 모바일 / 공용 / 기타
질문 3. 맥락: 신규 프로젝트 / 기존 레포 / 학습·실험

선택 → 대응 파일:
- 초보자 → `prompts/startup/beginner.md`
- 중급 → `prompts/startup/intermediate.md`
- 집 → `prompts/startup/env-home.md`
- 회사 → `prompts/startup/env-office.md`
- 모바일 → `prompts/startup/env-mobile.md`
- 공용/타인 기기 → `prompts/startup/env-common.md`
- 신규 프로젝트 → `prompts/startup/project-new.md`
- 기존 레포 → `prompts/startup/project-existing.md`

보통은 [숙련도 1개] + [환경 1개] + [맥락 1개] = **3개** 를 병합해서 실행한다.
병합 순서: 환경 → 숙련도 → 맥락. (환경 원칙이 최우선)

실행 전에 어떤 조합을 쓸지 나에게 한 번 보여주고 승인받아.
